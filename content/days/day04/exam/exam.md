Level 1 (Day 1〜4) の内容を確認する試験です。Day 4 のレッスンと演習を終えてから受けてください。合格すると、Level 2 (React) に進む準備ができています。

## 範囲

- **Day 1** — `const` / `let`、アロー関数、配列・オブジェクトの分割代入 (リネーム・デフォルト値)、スプレッド / 残余
- **Day 2** — 省略記法 `{ name }`、計算されたキー `{ [KEY]: v }`、`map` / `filter` / `find` / `some` / `every`、`Object.entries` / `fromEntries`、`?.`、`??` と `||` の違い
- **Day 3** — 型注釈、ユニオン型と絞り込み、リテラル型、`as const`、`typeof` / `keyof typeof` / `(typeof X)[number]`
- **Day 4** — ジェネリクス、ユーティリティ型、`T['key']`、`satisfies`、import / export、Promise と async / await

新しい知識は出ません。レッスンで扱ったことだけです。

## 形式と採点

| | 数 | 配点 |
| --- | --- | --- |
| 選択問題 (コード読解中心) | 12 問 | 各 1 点 |
| 演習 (実装・型・非同期) | 3 問 | 各 3 点 |

- 合計 21 点。**80% (17 点) 以上で合格** です
- 演習で「解答を表示」すると、その演習は 0 点になります (ヒントは見ても減点されません)
- 目安の時間は **40 分** です

## 進め方

1. まずレッスンやメモを見ずに、選択問題を解きます。コードは頭の中で実行してみましょう
2. 演習は、テストが全部通れば正解です (演習 2 は型エラー 0 件も必要)。テストのファイルは読んでかまいません
   - 演習 1: 分割代入・スプレッド・計算されたキーでオブジェクトを組み立てる
   - 演習 2: `as const` とユーティリティ型で型を作る (型チェック演習)
   - 演習 3: `async` / `await` と絞り込みで、失敗や `null` を扱う
3. 間違えた問題は解説を読み、解説に書いてある Day のレッスンを見直しましょう

不合格でも、**何度でも受け直せます**。点数よりも「間違えた理由がわかる」ことのほうが大切です。
