注文一覧の表です。ページ番号は URL の `?page=` (1 始まり) に置き、サーバー (`api.ts` の `getOrdersPage`) から 1 ページ分の行と全件数を受け取って表示しています (`manualPagination: true` + `rowCount`)。

ところが、次のようなバグ報告が来ました。

- 最初のページなのに「2 / 5 ページ」と表示され、「前へ」が押せる
- 「次へ」を押すと、2 ページ目を飛ばして 3 ページ目に行ってしまう

`main.tsx` を **1 か所** 直してください。

```text
URL: (page なし)  → 注文 #1〜#10   「1 / 5 ページ」 [前へ(押せない)] [次へ]
  次へ →
URL: ?page=2      → 注文 #11〜#20  「2 / 5 ページ」
```

全部で 47 件、1 ページ 10 件なので 5 ページです。`?page=1` にあたるときは、デフォルト値なので URL から `page` が消えます (Day 11)。
