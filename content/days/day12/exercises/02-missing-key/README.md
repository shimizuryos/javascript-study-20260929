title: カテゴリを切り替えても一覧が変わらない
hints:
  - "queryFn の中で使っている値のうち、queryKey に入っていないものはどれでしょう?"
  - "queryKey を `['products', category]` にすると、カテゴリごとに別のキャッシュになり、切り替えたときに自動で取得されます。"
---

商品一覧の画面で「『食品』タブを押しても、本の一覧が表示されたまま」というバグ報告が来ました。`fetchProducts` 自体は正しく動いています。

`main.tsx` の `ProductList` を **1 か所** 直して、タブを切り替えると一覧も切り替わるようにしてください。キャッシュのキーは `['products', カテゴリ]` の形にします。

```text
「本」タブ   → TypeScript 入門 / React の本
「食品」タブ → りんご / コーヒー豆
「本」タブに戻る → すぐに本の一覧が出る (キャッシュが残っているので「読み込み中…」にならない)
```
