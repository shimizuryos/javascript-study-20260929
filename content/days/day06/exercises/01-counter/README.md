カウンターを完成させてください。プレビュー欄で実際にボタンを押して確かめられます。

| ボタン | 動き |
| --- | --- |
| `+1` | 1 増やす |
| `+3` | 3 増やす。**`increment` を 3 回呼ぶ** 今の書き方のまま動くようにする |
| `-1` | 1 減らす。count が 0 以下のときは押せない (`disabled`) |
| `リセット` | `initial` (props、省略時 0) に戻す |

表示は `<p>カウント: 3</p>` の形です。

今のコードは `+3` を押しても 1 しか増えません。`addThree` はそのままにして、`increment` の書き方を直しましょう (なぜ直るのかはレッスンの「関数型更新」)。
